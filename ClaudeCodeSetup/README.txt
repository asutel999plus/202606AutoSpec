AutoSpec セットアップツール(Claude Code 初期セットアップ)
====================================

【AutoSpecとは?】
AutoSpecは、Claude Codeを使って仕様書を自動生成するためのツールです。
このZIP(Setup.bat)は、AutoSpec本体を使い始めるための準備(セットアップ)
と、AutoSpecの動作モード切り替えを行う部分です。

※現時点(ver0)では、仕様書を自動生成する本体(AutoSpec.bat)はまだ
  含まれていません。今回のバージョンは、Claude Codeのセットアップと、
  AutoSpecの動作モード(Safety/Auto)を切り替える土台のみです。
  仕様書自動生成機能は、今後のバージョンで追加される予定です。

【これは何をするツールですか?】
ダブルクリックひとつで、以下の5つを自動設定します。
  1. AutoSpecの動作モード(Safety/Auto)の選択と、Autoモード用の権限設定
  2. Claude Code CLI(コマンドライン版)のインストール
  3. マイク(音声入力)・Claudeの応答を日本語に設定
  4. ファイル削除・commit・push・mergeなど、元に戻しにくい操作、あるいは
     元に戻せない操作の実行前に、必ず確認画面を出す設定
  5. CLAUDE.md(応答を日本語で行う・上記項目4のような操作の前は確認を
     取る等の指示ファイル)の作成・追記

【使う前に必要なもの】
  - Visual Studio Code がインストールされていること
  - Claude Pro / Max / Team のいずれかのプランを契約していること
  - インターネット接続

【使い方】
  1. このZIPファイルを、好きな場所に「展開(解凍)」してください。
     (ZIPを展開せずに中身を直接ダブルクリックすると、正しく動作しません)
  2. 展開してできたフォルダの中の「Setup.bat」をダブルクリックします。
  3. 黒い画面(コマンドプロンプト)が開くので、動作モードを選ぶメニューが
     表示されます。↑↓キー+Enter、または数字キー(1/2/3)で選んでください。
     何も操作せずEnterだけ押した場合は、安全側のSafetyモードになります。
  4. その後は画面の指示に従ってキーを押してください。
  5. 処理が終わったら、いったんウィンドウを閉じてください。
  6. 新しくターミナル(またはVS Code)を開き、「claude」と入力します。
  7. ブラウザでログイン画面が出るので、Claudeアカウントでログインしてください。

【AutoSpecの動作モードについて】
Setup.bat起動のたびに、AutoSpecが確認画面をどこまで省略してよいかを
決める「動作モード」を、次の3つから選べます。

  1. Safetyモード(デフォルト)
     ファイル削除・commit・push等、元に戻しにくい操作の前に、
     必ず確認画面が出ます。迷ったらこれを選んでください。

  2. 仕様書生成完了までAutoモード
     AutoSpec.batによる仕様書生成が完了するまでの間だけ、確認を省略して
     自動で進めます。完了すると自動的にSafetyモードへ戻ります。
     夜間などにパソコンを離れて放置する場合向けです。
     ※現時点(ver0)ではAutoSpec.bat本体が未実装のため、このモードを
       選んでも自動でSafetyモードには戻りません。ver1以降で対応予定です。

  3. Autoモード
     手動でSafetyモードに戻すまで、確認を省略して自動で進み続けます。

  選んだモードは、Setup.batがあるフォルダ直下の「.autospec_mode」という
  ファイルに記録されます。

【AutoSpecのAutoモードの権限は、どこに効きますか?】
このツール(Setup.bat)は、以下の2種類の設定を行います。

  ・あなたのユーザーアカウント全体に効く設定
    「マイクや応答を日本語にする」「削除・commit・push等の前に確認を
    出す」といった設定は、あなたがログインしているWindowsユーザー
    アカウントの共通設定(ユーザーフォルダ内の .claude フォルダ)に
    書き込まれます。同じパソコンでも、別のユーザーアカウントには
    反映されません。
    あなたのアカウントであれば、どのプロジェクトフォルダでSetup.bat
    を実行しても、同じ共通設定が更新されます。

    このうち「CLAUDE.md」というファイル(ユーザーフォルダの .claude
    フォルダの中)は、Claude Codeがあなたのアカウントで動くとき、
    どのプロジェクトを開いていても毎回必ず読み込まれる「恒久的な
    指示書」です。ここに書き込まれたルール(言語設定・確認ルールなど)
    は、一度書き込まれれば以後ずっと有効になります。
    Autoモード関連のルールは、下記の理由によりここには書き込みません。

  ・このプロジェクトだけに効く設定(Autoモードの権限)
    Autoモードで「確認を省略してよいか」を判断する権限設定は、
    Setup.batを置いたプロジェクトフォルダの中だけ(.claude フォルダ)に
    書き込まれます。他のプロジェクトフォルダには一切影響しません。
    そのため、あるプロジェクトでAutoモードにしても、別のプロジェクトを
    Claude Codeで開いたときは普段どおりSafetyモード相当の確認が
    求められます。プロジェクトごとに安全に使い分けられる仕組みです。

    後述の「確認保留・後回しルール」も、この考え方に合わせて、あなたの
    アカウント全体ではなく、Setup.batを置いたプロジェクトフォルダ直下の
    「CLAUDE.md」(こちらはプロジェクトごとの指示書です)に書き込まれます。
    他のプロジェクトのCLAUDE.mdには影響しません。

  なお、Autoモードであっても、git/svnの状態を変更する操作
  (commit・push・reset --hard・ブランチ操作など)は、モードに関わらず
  常に自動的にスキップされます。スキップした内容は、そのプロジェクト
  フォルダ直下の「autospec_action_log.md」に記録されます。

  また、あなたが用意した既存ファイル(git管理外で、かつAutoSpecが
  そのセッション中に新規作成したものでもないファイル)を編集・削除
  しようとした場合も、その場で確認を求めて処理を止めることはせず、
  いったんスキップしてログに記録し、他に進められる作業があれば
  先に済ませてから、最後にまとめてユーザーに確認を求めるように
  動作します(このルールは、プロジェクトフォルダ直下のCLAUDE.mdに
  書き込まれます。上記のとおり、あなたのアカウント全体には影響しません)。

【セキュリティの警告が出た場合】
ZIPをダウンロードした直後は、Windowsが「このファイルは安全か分かりません」
という警告(SmartScreenなど)を表示することがあります。
信頼できる配布元から受け取ったファイルであれば、「詳細情報」→「実行」を選んで
進めて問題ありません。

【もう一度実行しても大丈夫?】
はい。既にインストール済みの項目はスキップされ、設定は上書きではなく
追加されるだけなので、何度実行しても安全です。
