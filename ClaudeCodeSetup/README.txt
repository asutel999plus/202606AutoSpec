Claude Code 初期セットアップツール
====================================

【これは何をするツールですか?】
ダブルクリックひとつで、以下の4つを自動設定します。
  1. Claude Code CLI(コマンドライン版)のインストール
  2. マイク(音声入力)・Claudeの応答を日本語に設定
  3. ファイル削除・commit・push・mergeなど、元に戻しにくい操作、あるいは
     元に戻せない操作の実行前に、必ず確認画面を出す設定
  4. CLAUDE.md(応答を日本語で行う・上記項目3のような操作の前は確認を
     取る等の指示ファイル)の作成・追記

【使う前に必要なもの】
  - Visual Studio Code がインストールされていること
  - Claude Pro / Max / Team のいずれかのプランを契約していること
  - インターネット接続

【使い方】
  1. このZIPファイルを、好きな場所に「展開(解凍)」してください。
     (ZIPを展開せずに中身を直接ダブルクリックすると、正しく動作しません)
  2. 展開してできたフォルダの中の「Setup.bat」をダブルクリックします。
  3. 黒い画面(コマンドプロンプト)が開くので、画面の指示に従ってキーを押します。
  4. 処理が終わったら、いったんウィンドウを閉じてください。
  5. 新しくターミナル(またはVS Code)を開き、「claude」と入力します。
  6. ブラウザでログイン画面が出るので、Claudeアカウントでログインしてください。

【セキュリティの警告が出た場合】
ZIPをダウンロードした直後は、Windowsが「このファイルは安全か分かりません」
という警告(SmartScreenなど)を表示することがあります。
信頼できる配布元から受け取ったファイルであれば、「詳細情報」→「実行」を選んで
進めて問題ありません。

【もう一度実行しても大丈夫?】
はい。既にインストール済みの項目はスキップされ、設定は上書きではなく
追加されるだけなので、何度実行しても安全です。
